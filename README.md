# wanderlog | dream it, plan it ✨

**wanderlog** is a sophisticated, Pinterest-inspired travel planning application designed for the modern explorer. It transforms the way you discover, pin, and budget for your next adventure.

## 🌟 Features
- **Dream Board:** A visual grid of your travel aspirations.
- **Pinterest-Style Explore:** Discover hand-picked destinations with dreamy imagery and curated vibes.
- **Interactive Mapping:** Pin your dreams on a global board with custom "card" markers.
- **Immersive Trip Tracking:** Follow your travel story with full-screen itineraries and real-time budget insights.
- **Smart Budgeting:** Data-driven spending logs to keep your dream journey on track.

## 🎨 Aesthetic
Built with the **Dream Palette**:
- Soft Cream, Warm Sand, and Blush highlights.
- Elegant typography: **Playfair Display** (Serif) & **Outfit** (Sans).
- Glassmorphic UI components and smooth, tactile animations.

## 🏗️ Architecture
- **Backend:** Flask (Python)
- **Frontend:** Vanilla JS (Modular ESM-style)
- **Persistence:** LocalStorage (State-aware)
- **Mapping:** Leaflet.js
- **Styling:** Custom CSS3 with Variable-based Design System

## 🚀 Deployment
Ready for deployment on **Render**, **Heroku**, or **Vercel**.
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run locally: `python app.py`
4. Deploy: The `Procfile` is configured for production serving via `gunicorn`.
